# skudio

A visual development environment for scikit-learn. Build, tune and evaluate real `sklearn` pipelines through a browser UI, then export them as ordinary, readable Python code.

Not AutoML. Not a proprietary low-code abstraction. The generated code is idiomatic scikit-learn that runs standalone.

## Status

Pre-alpha. Version `0.2.0`.
